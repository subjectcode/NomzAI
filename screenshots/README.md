# Nomz Application Screenshots

Active production screenshots captured from live Android client:

- `01_beranda_home.png` — **Beranda (Home)**: User greeting, food rescue impact summary, quick scan action, and 5-tab bottom navigation.
- `02_deteksi_bahan_editor.png` — **Hasil Deteksi Bahan**: Multimodal vision detection results with real kitchen ingredients thumbnail (8 bahan terdeteksi: nasi, bawang putih, bawang merah, daging ayam, dll.), confidence badges, interactive quantity steppers, '+ Tambah' button, and recipe recommendation trigger.
- `03_rekomendasi_masakan.png` — **Rekomendasi Masakan**: Langflow V2 recipe matches with pantry match score, cooking style filters (Semua, Tumis, Goreng, Kukus), and recipe metadata.
- `04_detail_resep_panduan.png` — **Detail Resep**: Cooking preparation times, difficulty, budget estimate, pantry checklist, extra seasoning checklist, and 9-step guided cooking instructions.
- `05_profil_dapur.png` — **Profil Saya**: User profile card, food waste reduction metrics (kg saved, money saved, recipes cooked), and kitchen management links.
